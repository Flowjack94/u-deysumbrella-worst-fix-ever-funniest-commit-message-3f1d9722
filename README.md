One commit message, 88 characters, for the fix that made everything worse:
the login check was deleted so nobody would get locked out — and all 12,000
accounts were left wide open. Git blame says who sent it.

`main.py` writes the commit message to `/output/entry.txt` and prints it with
its character count. A `validate_entry()` gate enforces the commit-message
shape, the 100-character cap, and a concrete-artifact punchline.
